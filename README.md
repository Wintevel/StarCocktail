# StarCocktail · 별빛 바

손님의 주문을 듣고 잔·얼음·재료·장식을 골라 칵테일을 3D로 제조하며 7일 동안 바를 운영하는 브라우저 게임입니다.
빛나는 백바 선반과 네온 간판이 있는 바 카운터에서, 계단식 진열대의 병을 집어 유리잔에 붓고, 젓고, 장식을 올려 걸어 들어온 손님에게 건넵니다.
붕괴: 스타레일 페나코니의 칵테일 제조 이벤트(「Vignettes in a Cup」)의 흐름을 참고했고, 그림과 캐릭터·재료는 모두 직접 만든 도형과 이름입니다.

## 플레이

브라우저에서 바로: https://wintevel.github.io/StarCocktail/ (main에 push되면 자동 배포)

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 규칙 테스트 (모든 주문·레시피가 실제로 만들 수 있는지 전수 검사 포함)
npm run build    # dist/ 에 정적 파일 생성
```

## 플레이 방법

별빛 바의 **7일 영업**을 맡습니다. 하루를 시작하면 손님이 왼쪽에서 걸어 들어와 카운터 앞에 서서 주문하고, 술을 받으면 잔을 들고 오른쪽으로 나갑니다.

화면에는 오른쪽 패널이 없고, 모든 조작을 바 공간 안에서 합니다. 카메라는 단계에 따라 세 번 움직입니다.

1. **손님 맞이**: 손님이 자리에 서면 화면 가운데 위에 말풍선으로 대사와 주문 칩이 뜹니다.
2. **잔 고르기**: 카운터 왼쪽 쟁반에 진열된 잔을 누릅니다. 아직 입고되지 않은 잔은 어둡게 보이고, 올려 보면 입고 날짜가 나옵니다. 잔마다 부을 수 있는 횟수가 다릅니다 (록·쿠페 3, 와인 4, 하이볼 5).
3. **제조 화면**: 잔을 고르면 카메라가 가운데 잔과 오른쪽 진열대로 다가갑니다. 잔 위에 뜬 칩으로 얼음을 고릅니다(얼음 가득은 도수 -1).
4. 진열대의 **병을 잔 위로 끌어다 놓아** 붓습니다(톡 누르기도 됩니다). 병에 포인터를 올리면 테두리가 밝아지고 이름·종류·값·맛 변화가 보입니다. 잔 밖에 놓으면 병이 제자리로 돌아갑니다. 터치로도 끌 수 있습니다.
   - 잔 왼쪽의 **맛 게이지**(단맛·도수·바디)에서 점선 구간이 손님이 원하는 범위입니다.
   - 잔 오른쪽의 가는 세로 막대가 **부은 횟수 / 최대 횟수**입니다.
   - 잔 아래 버튼으로 한 번 저을 수 있습니다(층이 섞이고 바디 -1). 「다시」는 잔부터 새로 시작합니다.
5. **제조 완료**를 누르면 카메라가 잔 가까이로 가고, 잔 위에 장식 카드가 부채꼴로 펼쳐집니다. ←/→ 키, 화살표 버튼, 마우스 휠로 넘기고 카드를 눌러 고른 뒤 **서빙**합니다. 이때 왼쪽 위에 주문, 왼쪽에 작게 줄어든 「현재 맛」, 오른쪽 위에 레시피북 아이콘이 있습니다.
6. 판정은 조건을 모두 맞추면 완벽, 하나 틀리면 아쉬움, 그 이상은 실패입니다. 손님은 잔을 들고 오른쪽으로 나갑니다.

- **레시피북**: 진열대 오른쪽에 세워 둔 책을 누르면 펼쳐집니다.
- **서랍**: 카운터 오른쪽 아래 나무 손잡이를 누르면 열립니다. 잔고와 오늘 장부(마감 때 낼 임대료 포함)를 보고, 언제든 상점에서 가게를 꾸미거나 재료를 미리 주문할 수 있습니다. 미리 주문한 재료는 **다음 날 아침에** 도착합니다.
- **시계**: 오른쪽 위에 Day와 오늘 손님 진행이 표시됩니다.

조건에 맞는 조합을 만들면 이름 있는 레시피가 레시피북에 기록됩니다(브라우저에 저장). 「자유 제조」 모드에서는 주문 없이, 재료비 없이 그때까지 입고된 재료로 실험할 수 있습니다.

## 7일 영업과 경영

| 날 | 손님 | 새로 입고 |
| --- | --- | --- |
| Day 1 | 2명 | 진·위스키·시럽·시트러스·소다, 록·하이볼 잔, 레몬 |
| Day 2 | 3명 | 와인, 쿠페 잔, 민트 |
| Day 3 | 3명 | 크림, 와인 잔, 체리 |
| Day 4 | 4명 | 비터스 |
| Day 5 | 4명 | 성운 리큐르, 별 장식 |
| Day 6 | 5명 | 꿀빛 미드 |
| Day 7 | 5명 | 혜성 에스프레소 |

- 주문 조건은 첫날 2개에서 마지막 날 3~5개(잔·얼음·젓기·층·장식 지정 포함)로 늘어납니다. 모든 주문은 그날까지 입고된 재료만으로 완벽하게 만들 수 있음을 테스트가 확인합니다.
- 돈: 시작 ✦30. 한 잔 판매가 ✦20에 팁(완벽 30, 아쉬움 10, 실패 0). 재료비는 부을 때마다(✦1~6), 장식은 올릴 때 나갑니다. 다시 만들면 부은 재료값은 버려집니다.
- 하루 마감 때 임대료가 나갑니다(Day 1 ✦20부터 하루 ✦10씩 오름). 돈이 모자라면 빚(빨간 숫자)으로 넘어갑니다.
- 서랍이나 마감 뒤 상점에서 가게를 꾸밀 수 있습니다: 도매 계약(재료비 -30%, ✦60), 벨벳 의자(판매가 +5, ✦70), 별빛 축음기(실패해도 판매가 절반, ✦80), 네온 간판 정비(팁 +50%, ✦90). 나중에 들어올 재료를 ✦40에 미리 주문할 수도 있습니다(다음 날 도착).
- 7일이 끝나면 남은 돈과 완벽한 잔 수로 칭호를 받습니다. 진행은 매일 아침 브라우저에 저장되어 이어서 할 수 있습니다.

## 글꼴

역할마다 글꼴을 나눠 씁니다(`src/style.css`의 `--font-*` 변수): 로고 Cinzel, 한글 제목 Do Hyeon, 본문 Pretendard, 숫자·시계·돈 JetBrains Mono, 손님 대사 Gaegu(손글씨), 레시피북 Gowun Batang(명조). Cinzel·JetBrains Mono는 `@fontsource`로 함께 묶고, 한글 글꼴은 글자 수가 많아 Google Fonts에서 나눠 받습니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/data.ts` | 재료·잔·얼음·장식·손님·레시피 데이터 |
| `src/mix.ts` | 붓기·젓기·속성 계산·판정 같은 순수 규칙 |
| `src/campaign.ts` | 7일 일정(날마다 손님·주문·입고), 매출·재료비·임대료·상점, 저장 |
| `src/solver.ts` | 주문을 주어진 재료로 만들 수 있는지 찾는 전수 탐색 (테스트용) |
| `src/three/stage.ts` | 3D 무대 (Three.js): 카메라 3단계, 병 끌어다 붓기·잔/책 누르기, 잔·술·얼음·장식, 붓기·젓기 연출, 손님 입장·퇴장, 블룸 후처리 |
| `src/three/rack.ts` | 카운터 위 계단식 병 진열대: 입고된 병 배치, 마우스를 올린 병의 빛나는 테두리, 끌기·붓기용 병 빌려주기 |
| `src/three/props.ts` | 카운터 왼쪽 잔 쟁반(잔 고르기), 진열대 옆 레시피북 |
| `src/three/figure.ts` | 손님 인형 (셀 셰이딩 3D 흉상, 표정·걸음) |
| `src/three/bar.ts` | 바 배경: 카운터, 백바 선반과 병, 아르데코 장식, 네온, 조명 |
| `src/three/models.ts` | 잔·병·얼음·장식 3D 모델 (회전체와 기본 도형) |
| `src/three/icons.ts` | 버튼 아이콘을 3D 모델로 렌더해 이미지로 생성 |
| `src/three/textures.ts` | 나뭇결·네온·라벨 등 코드로 그린 텍스처 |
| `src/main.ts` | 화면 상태와 UI (영업 흐름, 주문 말풍선, 잔 둘레 게이지·횟수 바·장식 카드, 서랍, 결산 화면) |
| `src/mix.test.ts`, `src/campaign.test.ts` | 규칙·경영·일정 테스트 |

새 손님 주문은 `src/campaign.ts`의 날짜별 `visits`에, 레시피는 `src/data.ts`에 조건(`Constraint`)으로 추가하면 되고, 테스트가 그 조건을 그날 재료로 실제로 만들 수 있는지 자동으로 확인합니다.
