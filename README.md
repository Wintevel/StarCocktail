# StarCocktail · 별빛 바

손님의 주문을 듣고 잔·얼음·재료·장식을 골라 칵테일을 시각적으로 제조하는 브라우저 게임입니다.
붕괴: 스타레일 페나코니의 칵테일 제조 이벤트(「Vignettes in a Cup」)의 흐름을 참고했고, 그림과 캐릭터·재료는 모두 직접 만든 도형과 이름입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 규칙 테스트 (모든 주문·레시피가 실제로 만들 수 있는지 전수 검사 포함)
npm run build    # dist/ 에 정적 파일 생성
```

## 플레이 방법

1. 손님의 대사와 주문 칩을 읽습니다.
2. 잔을 고릅니다. 잔마다 부을 수 있는 횟수가 다릅니다 (록·쿠페 3, 와인 4, 하이볼 5).
3. 얼음을 고릅니다. 얼음 가득은 도수를 1 낮춥니다.
4. 재료를 한 번에 하나씩 붓습니다. 재료마다 **단맛·도수·바디** 값이 더해지고, 아래 게이지의 점선 구간이 손님이 원하는 범위입니다.
5. 필요하면 한 번 저어 섞습니다. 그때까지 부은 재료가 한 색으로 섞이고 바디가 1 낮아집니다. 젓지 않으면 층이 그대로 남습니다.
6. 장식을 올리고 서빙하면 판정합니다. 조건을 모두 맞추면 완벽(팁 30), 하나 틀리면 아쉬움(팁 10), 그 이상은 실패입니다.

조건에 맞는 조합을 만들면 이름 있는 레시피가 레시피북에 기록됩니다(브라우저에 저장). 「자유 제조」 모드에서는 주문 없이 실험할 수 있습니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/data.ts` | 재료·잔·얼음·장식·손님·레시피 데이터 |
| `src/mix.ts` | 붓기·젓기·속성 계산·판정 같은 순수 규칙 |
| `src/render.ts` | 캔버스 렌더러 (잔 모양, 층, 붓기·젓기·얼음·장식 애니메이션) |
| `src/main.ts` | 화면 상태와 UI |
| `src/mix.test.ts` | 규칙 테스트 |

새 손님이나 레시피는 `src/data.ts`에 조건(`Constraint`)으로 추가하면 되고, 테스트가 그 조건을 실제로 만들 수 있는지 자동으로 확인합니다.
