# StarCocktail · 별빛 바

정거장 도시 **녹턴**의 작은 바를 맡아, 18:00~04:00 실시간으로 흐르는 밤을 7일 동안(그 뒤로는 무한히) 운영하는 브라우저 게임입니다.
가게 안 스툴 네 개에 손님이 띄엄띄엄 들어와 앉고, 앉은 손님을 누르면 그 손님을 위한 칵테일을 만드는 제조대로 넘어갑니다. 잔을 건네면 손님은 반응하고 잔을 들고 나갑니다.
바텐더는 술만 파는 게 아니라 카운터 아래 진열장의 물건을 팔고, 단골들이 맡긴 말·물건·소문을 서로 이어 줍니다. 7일째 꿈의 축제에서 다섯 줄기의 이야기가 저마다의 결말로 갈립니다.
화면은 흑백 신문지에 빨강 하나만 얹은 신문·만화 원고 화풍이고, 손님은 굵은 먹선·빗금·망점으로 그린 극화체(8~9등신) 인물입니다. 가게는 2D(SVG), 제조대는 3D입니다.
매일 아침 영업 전에는 「녹턴 야간 신문」 한 면이 펼쳐져, 어젯밤 바텐더가 고른 선택이 그 결과와 함께 기사로 실립니다.
칵테일 제조 흐름과 화풍은 다른 게임들을 참고했지만, 그림·캐릭터·재료·이름은 모두 코드로 직접 만든 것입니다(외부 이미지 없음).

## 플레이

브라우저에서 바로: https://wintevel.github.io/StarCocktail/ (main에 push되면 자동 배포)

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 규칙 테스트 (모든 주문·레시피가 실제로 만들 수 있는지, 하루 주문을 가득 찬 병으로 다 만들 수 있는지 전수 검사 포함)
npm run build    # dist/ 에 정적 파일 생성
```

## 이야기

녹턴은 막차가 끊긴 뒤에야 깨어나는 정거장 도시입니다. 별빛 바의 주인 할은 어느 날 사라졌고, 당신이 그 대신 카운터에 섭니다.
단골 여덟 명(졸린 막차 차장 미오, 비 오는 날의 탐정 그레이, 무대 뒤의 가수 세레나, 떠돌이 시인 에반, 은퇴한 우주 해적 볼트 선장, 꿈 관리국 감독관 노르마, 꼬마 배달부 피피, 축제의 주인공 레일라)은 저마다 비밀과 바람이 있고 서로 얽혀 있습니다.
바텐더는 술을 팔고, 단골들의 이야기를 서로 이어 주는 사람입니다.

녹턴의 오래된 관습 「카운터의 약속」: 바 카운터에서 한 말은 바텐더가 맡습니다. 전할지, 묻어 둘지, 어떻게 전할지는 바텐더가 정합니다.
할은 단골마다 끝내지 못한 이야기 한 줄씩을 「약속 장부」에 남겼고, 바텐더는 7일 동안 그 줄을 하나씩 그어 갑니다. 설정은 `정리-v5-세계관.md`, 손님별 비밀·바람·관계·열쇠 맛은 `src/world.ts`, 이야기 장면과 규칙은 `src/story.ts`에 있습니다.

## 플레이 방법

### 가게 화면

- 가게는 매일 **18:00에 열어 04:00에 닫습니다**. 손님은 왼쪽 문으로 들어와 **빈 스툴(4개)** 가운데 하나에 앉습니다.
- 손님은 두 부류입니다. 이야기 줄기를 가진 **단골**은 날마다 정해진 1~3명만 오고(일정표에 이름이 있는 손님), 나머지는 **지나가는 손님**입니다. 지나가는 손님은 손님마다 이름(두 글자 우리말 이름)·직업(막차를 놓친 승객, 시계탑 수리공, 천문대 조수…)·생김새·주문을 무작위로 정하며(같은 날은 늘 같은 손님), 이야기·신뢰·단골 수첩 없이 잔을 받은 뒤 짧은 잡담만 합니다.
- 앉은 손님 머리 위 이름표에 `!` 표시와 **인내 막대**가 있습니다. 손님(또는 이름표)에 포인터를 올리면 빨간 테두리로 강조되고 칭호와 「주문 받기」가 보입니다.
- **앉은 손님을 누르면** 화면이 사선으로 넘어가며 그 손님의 제조대가 열립니다.
- 다른 손님은 자리에서 기다립니다. 인내가 30% 아래로 내려가면 초조해하며(발 구르기, 막대가 빨강) 한마디 하고, 다 떨어지면 화가 나서 **돈을 내지 않고** 나갑니다(마감 화면에 「기다리다 떠남」).
- 아래 가운데 안내 띠에 지금 할 일과 「남은 손님 · 앉은 손님 n/4」가 나옵니다. 오른쪽 아래 **서랍**, 오른쪽 위 **Day·시계**, **레시피북**, **메뉴**가 있습니다.

### 제조대

가운데에 3D 잔이, 오른쪽에 **단계 판**이 있습니다. 판에는 지금 단계의 카드만 나오고, 맨 위 단계 표시(① 잔 → ② 얼음 → ③ 재료 → ④ 젓기 → ⑤ 장식)로 지나온 단계를 눌러 되돌아갈 수 있습니다. 판 아래 **다음 단계**·**이전** 버튼이 있고, 잔 아래 **↺ 초기화**(휴대폰에서는 판 아래 ↺)는 잔부터 새로 시작합니다.

1. 왼쪽 위 **주문 카드**에 손님 얼굴·이름·칭호와 주문 대사가 있습니다(휴대폰에서는 한 줄로 접혀 있고 ▾로 펼칩니다). 레시피 이름 주문에는 레시피북 칩과, 아직 모르는 레시피면 힌트, 아는 레시피면 조건 칩이 붙습니다. 카드 아래 **← 가게로**(또는 Esc)는 만들던 잔을 그대로 둔 채 가게로 돌아가고, **돌려보내기**는 만들 수 없는 주문(필요한 병이 비었을 때 등)을 사과하고 보냅니다(수입 없음, 부은 재료는 버려짐).
2. 위쪽 **자리 띠**에 다른 스툴의 손님과 인내 막대가 보입니다. 눌러서 바로 그 손님으로 바꿀 수 있습니다(만들던 잔은 비워집니다).
3. **① 잔 고르기**: 잔 카드를 누르면 카운터에 잔이 놓이고 얼음 단계로 넘어갑니다. 아직 입고되지 않은 잔은 점선 카드에 입고 날짜가 적혀 있습니다. 잔마다 부을 수 있는 횟수가 다릅니다(록·쿠페 3, 와인 4, 하이볼 5). 재료를 부은 뒤 잔을 바꾸면 부은 재료·젓기·장식이 비워지고 얼음은 남습니다.
4. **② 얼음**을 고르면(얼음 가득은 도수 -1) 재료 단계로 넘어갑니다. 얼음은 부은 재료를 그대로 둔 채 바꿀 수 있습니다.
5. **③ 재료**: 재료 카드를 **한 번 누를 때마다 한 번** 붓습니다(위에서 술 줄기가 떨어집니다). 카드에는 맛 변화, 부은 횟수(×n), **남은 양**(다섯 칸, 빈 병이면 「빈 병」)이 보이고, 빈 병이거나 잔이 가득 차면 카드가 잠깁니다. 한 번 이상 부어야 다음 단계로 갑니다.
   - 잔을 고르면 왼쪽 아래에 **맛 게이지**(단맛·도수·바디)가 나옵니다. 점선 구간이 손님이 원하는 범위입니다. 수치가 끝 단계(**±4**)에 닿으면 게이지 끝의 **맛 키워드**가 켜집니다: 단맛 씁쓸함/달콤함, 도수 순함/독함, 바디 산뜻함/묵직함, 경향 완곡함/직설적.
   - 잔 옆 세로 막대가 **부은 횟수 / 최대 횟수**입니다.
6. **④ 젓기**: 「젓기」(층이 섞이고 바디 -1, 한 번만) 또는 「젓지 않기」를 고릅니다. 저은 뒤에 이전 단계로 돌아가 더 부을 수도 있습니다.
7. **⑤ 장식**: 장식 카드가 고른 카드 자리에서 부채꼴로 펼쳐지며 들어옵니다. 카드를 누르거나 ←/→ 키로 고른 뒤 **내기**(자유 제조에서는 **완성**)를 누릅니다.
8. 화면이 가게로 돌아오고, 손님이 표정과 대사로 반응한 뒤 잔을 들고 나갑니다(스툴은 약 3초 뒤 빕니다). 왼쪽 위에 **결과 쪽지**가 판정·조건·수입을 보여 줍니다(✕로 닫기).

모든 카드는 Tab·Enter로도 고를 수 있고, 단계가 바뀌면 판 제목으로 초점이 옮겨 가며 부은 재료는 화면 읽기 프로그램에 알려 줍니다. 「움직임 줄이기」를 켜 두면 카드 등장은 짧은 흐려짐으로 바뀝니다.

판정은 조건을 모두 맞추면 완벽, 하나 틀리면 아쉬움, 그 이상은 실패입니다. 조건에 맞는 조합을 만들면 이름 있는 레시피가 레시피북에 기록됩니다(브라우저에 저장).

### 이야기 잇기 (Day 1~7)

- **「…」 표시**: 앉은 손님 이름표의 `!`가 말풍선 모양 `…`으로 바뀌면 할 말이 있다는 뜻입니다. 누르면 주문 전에 **이야기 만화**가 열리고, 이야기를 들은 뒤 「주문 받기 →」로 제조대로 갑니다(✕는 이야기를 다음으로 미루고 바로 주문을 받습니다).
- **잔을 받은 뒤**: 서빙한 뒤에도 할 말이 남은 손님은 잔을 든 채 스툴에 남아 `…`을 띄웁니다(점선 막대만큼, 게임 속 1시간 반 동안 기다려 줍니다). 눌러서 이야기를 마저 듣고 「배웅하기」로 보냅니다. 결과 기사에도 「할 말이 남았대요」가 붙습니다.
- **이야기 만화**: 단골의 이야기 장면은 화면 전체를 덮는 세로 만화(웹툰)로 읽습니다. 넓은 화면에서는 가운데 680px 기둥, 휴대폰에서는 화면 너비 그대로이고 뒤의 가게는 어둡게 가라앉습니다. 맨 위 머리띠에 손님 얼굴·이름·칭호·신뢰(★ 0~5)·날짜와 시각, 「시계 멈춤」 표시가 있습니다.
  - **칸 넘기기**: 칸은 하나씩 펼쳐집니다. 맨 아래에서 한 번 더 스크롤하거나, 화면을 누르거나(휴대폰에서는 위로 밀기), Enter·Space·↓·PageDown, 또는 아래 「▾ 다음 칸」 버튼으로 넘기면 새 칸이 나타나고 그 칸까지 저절로 내려 줍니다. 등장은 짧게(0.2~0.4초) 떠오르거나 미끄러지고, 「움직임 줄이기」를 켜 두면 곧바로 나타납니다.
  - **칸 구성**: 첫 칸은 카운터에 앉은 손님(장면 도장: 첫 이야기·전언·소문·고백·물건…, 잔을 내기 전/뒤, 잔을 낸 뒤라면 방금 낸 잔)입니다. 지문은 설명 상자, 대사는 말풍선이고, 칸마다 구도가 바뀝니다(넓은 칸·중간·얼굴 가까이·눈만 바짝·나란한 두 칸·집중선 칸). 외침은 터지는 말풍선, 목소리를 낮춘 말은 점선 말풍선, 맡아 둔 말이나 소문을 떠올리는 대목은 보랏빛 회상 칸(누구에게서 들은 말인지 함께), 오르골·편지·서류·동전 같은 물건 이야기는 물건 칸으로 그립니다.
  - **선택지**: 다 읽으면 칸 모양의 **선택지** 버튼 줄이 나옵니다(숫자 키 1~9로도 고릅니다). 조건이 안 맞는 선택지는 자물쇠와 이유를 달고 잠겨 보이고, 말투(그대로·완곡·직설·묻기)나 파는 값이 표시됩니다. 고쳐 전하기 장면에서는 선택지 앞에 **방금 낸 잔의 경향** 상자가 붙습니다. 고르면 바텐더의 말(하는 일이면 설명 상자)과 손님의 대답 칸, 결과(맡음·건넴·신뢰·돈) 쪽지가 이어지고, 찾는 물건이 있으면 「진열장」 줄에서 바로 권해 팔 수 있습니다(판 물건은 손님이 받아 드는 칸으로 그려집니다). 마지막 칸의 「주문 받기 →」·「배웅하기」로 카운터에 돌아가고, 이어지는 이야기가 있으면 「다음 이야기 ▸」(한 번에 세 장면까지)가 「#2 이어지는 이야기」 띠와 함께 아래에 이어 붙습니다.
  - **닫기**: 만화가 열려 있는 동안 시계와 인내는 멈추고, 닫으면 다시 흐릅니다. Esc(와 ✕)는 지금 닫을 수 있을 때만 닫습니다(잔을 내기 전 고르기 전에는 「이야기는 다음에 듣기」, 잔을 낸 뒤에는 고른 다음에 「배웅하기」). 대화 상자(`role="dialog"`)라서 Tab은 만화 안에서만 돌고, 닫으면 초점이 원래 자리로 돌아갑니다. 새 칸의 글은 화면 읽기 프로그램에 읽어 줍니다.
- **대화 카드**: 장면이 없는 대화(지나가는 손님의 짧은 잡담, 이야기 없이 진열장만 기웃거리는 손님)는 작은 신문지 카드로 뜹니다. 넓은 화면에서는 이야기하는 손님 반대편에, 휴대폰에서는 아래에서 올라오는 시트로 뜨고, 카드가 열려 있는 동안에도 시계와 인내는 멈춥니다.
- **전언 맡기**: 손님이 말·편지·서류·물건을 맡기면 왼쪽 아래 **수첩**의 「카운터의 약속」에 적힙니다. 받는 사람이 잔을 받은 뒤 **그대로 전하기 / 고쳐 전하기 / 묻어 두기** 중에 고릅니다. 고쳐 전할 때는 **방금 낸 잔의 경향**이 말투를 정합니다: 경향이 음수면 「완곡하게」, 양수면 「직설적으로」, 0이면 고칠 수 없습니다. 전할 것이 있는 손님의 주문 카드에는 귀띔이 붙고, 경향이 나오기 전(Day 1~3)이라도 게이지에 경향 축이 함께 보입니다.
- **소문 수첩**: 완벽한 잔을 받은 손님이 소문 하나를 흘립니다. 수첩에 적어 두면, 그 소문을 들려줄 만한 손님이 앉았을 때 「소문을 들려주기 / 말하지 않기」 장면이 나옵니다. 누구에게 무엇을 들려주는지가 손님 사이의 신뢰와 이야기를 바꿉니다.
- **고백의 잔**: 손님마다 **열쇠 맛**이 있습니다(미오 순함, 그레이 씁쓸함, 세레나 묵직함, 에반 완곡함, 볼트 독함, 노르마 달콤함, 피피 달콤함, 레일라 독함). 주문을 완벽하게 맞추면서 열쇠 맛 키워드까지 켜면 비밀을 털어놓습니다. 완벽한 잔을 한 번 내면(신뢰 1) 주문 카드와 단골 수첩에 열쇠 맛이 보입니다. 노르마의 주문은 늘 달지 않아서, 「몰래 단 것을 좋아한다」는 소문을 들은 뒤 완벽한 잔을 내면 서비스로 단 술을 낼 기회가 옵니다.
- **신뢰**: 완벽한 잔은 +1, 기다리다 지쳐 나가면 -1. 이야기 선택도 신뢰를 바꾸고, 어떤 장면은 신뢰가 있어야 열립니다.
- **유성 엽서**: 피피에게 별사탕을 팔아 배달을 맡기면, 수첩에서 전언·편지·서류를 **엽서로 부칠** 수 있습니다(진열장의 유성 엽서 한 장). 다음 날 아침 「그대로 전하기」로 배달되고, 그다음 날 아침 신문에 「엽서」 기사로 실립니다.
- **수첩·단골 수첩·약속 장부·이야기 기록**: 왼쪽 아래 「수첩」에 맡아 둔 것과 소문이 있습니다. 레시피북에는 쪽이 넷입니다: 레시피 / **단골 수첩**(만난 손님의 칭호·신뢰·열쇠 맛·알게 된 것, 만나지 않은 손님은 실루엣) / **약속 장부**(할의 손글씨 여덟 줄, 끝낸 약속은 빨간 줄과 「끝냄」 도장) / **이야기 기록**(날짜별 기록, 지난 아침 신문, 결말).
- **녹턴 야간 신문**: 매일 아침, 하루 시작 화면 전에 신문 한 면이 화면 가득 펼쳐집니다(버튼·Enter로 넘기고, 하루 시작 화면의 「아침 신문 다시 보기」로 다시 봅니다). 날짜·날씨·축제까지 남은 날이 적힌 제호 아래에,
  - 어젯밤의 **선택 하나하나가 기사 한 편**이 됩니다: 「어젯밤 바텐더가 세레나의 「고맙다는 말」을 미오에게 그대로 전했다. **→ 그 결과** 미오가 바텐더를 조금 더 믿게 되었다.」처럼 원인(바텐더가 한 일: 그대로·완곡하게·직설적으로 전하기, 묻어 두기, 소문 들려주기, 고백의 잔, 물건 팔기, 엽서 부치기…)과 결과(일어난 일, 신뢰 변화·맡은 것·돈 도장)를 나눠 싣습니다. 신문 기사가 걸린 선택·고백·전언이 1면에 오르고, 1면에는 그 손님의 상반신 사진이, 나머지 기사에는 작은 얼굴 사진이 붙습니다.
  - 이틀 전 밤의 선택 가운데 몇몇은 **후속 보도**로 다시 실립니다(오르골 자장가가 정거장까지 들렸다, 봉인된 보고서는 여전히 행방불명…).
  - 옆 칸에는 **어젯밤 카운터**(잔을 받은 손님, 단골·지나가는 손님 수, 완벽한 잔, 그냥 돌아간 손님, 진열장에서 판 물건), 거리 소식 단신, 광고 두 개가 실립니다.
  - 선택이 없던 아침은 그날의 기본 기사(Day 4 비 소식, Day 6~7 축제…)와 거리 소식으로 채웁니다. Day 1은 바가 다시 문을 여는 창간 특집, Day 8은 다섯 줄기의 결말을 싣는 축제 특집, 무한 영업에서는 단골 근황이 실립니다.
  - 펼친 신문은 저장되어(최근 12부) 레시피북 「이야기 기록」의 **지난 신문**에서 날짜를 눌러 다시 펼칠 수 있습니다. 하루 시작 화면에는 카운터 메모(축제 준비 현황, 맡아 둔 것, 최근 소문)가, 하루 마감 화면에는 「오늘의 이야기」가 붙습니다.
- **다섯 줄기와 결말**: 오르골(미오 → 세레나), 노랫말(에반의 「E」 → 세레나), 할 사건(그레이 ↔ 노르마의 봉인 보고서), 가족(볼트의 약속 ↔ 피피의 나침반), 꿈의 축제(레일라에게 필요한 가수·시·불꽃·허가·자금). Day 7 마감 때 줄기마다 3~4가지 결말 가운데 하나로 정해지고(예: 자장가의 주인 / 이름 없는 선물 / 미오의 오르골 / 멈춘 오르골), 7일 결산 「꿈의 축제 결산」에 결말과 덧붙는 한 줄이 실립니다. 끝내 전하지 못한 것은 기록에 남고 카운터는 비워집니다.
- **무한 영업**에는 이야기 장면이 없고, 단골들이 들어오며 축제의 결말에 따라 다른 말을 합니다. **자유 제조**에는 이야기가 없습니다.

- 서랍(또는 마감 뒤 상점)의 「진열장 물건」에서 하나씩 들여오면 **다음 날 아침** 진열장에 놓입니다(물건마다 오는 중인 것까지 5개). 도매 계약이 있으면 들여오는 값도 30% 쌉니다. 첫날에는 할이 남겨 둔 유성 엽서 3장과 별사탕 2봉지가 있습니다.
- 손님이 찾는 물건이 진열장에 있으면 이야기 만화의 마지막 칸(또는 대화 카드) 아래 「진열장」 줄에 「권하기」가 나오고, 한 번 방문에 물건마다 하나씩 팝니다. 할 이야기는 없지만 찾는 물건이 있는 손님은 잔을 받은 뒤 잠시(게임 속 24분) `✦` 표시를 띄우고 진열장을 기웃거립니다.
- 이야기에 묶인 물건(미오의 태엽, 에반의 편지지, 피피의 별사탕, 노르마의 꿈 보관병)은 그 장면의 선택지로 팔며, 진열장에 없으면 「서랍에서 들여오면 내일 아침 도착」이라는 이유와 함께 잠깁니다.
- 장부에는 「진열장 물건 판매」, 「물건 들여오기」, 「이야기로 오간 돈」(볼트의 선불 +✦30, 축제 후원 -✦60 등)이 따로 적힙니다.

### 주문 표현

손님은 네 가지 방식으로 주문합니다(첫 사흘 안에 모두 소개됩니다).

| 방식 | 예 | 보이는 것 |
| --- | --- | --- |
| 칩 | 「처음 와 봐요… 달달하고 순한 걸로」 | 대사 아래 조건 칩. 맛 키워드 조건은 강조 칩(「묵직함」) |
| 강조 대사 | 「사건이 꼬였어. **쓰고** **독한** 걸로」 | 대사 속 조건 표현에 밑줄. 맞추면 체크가 붙고, 올려 보면 정확한 조건 |
| 레시피 이름 | 「「달콤한 꿈」 하나 주세요」 | 레시피 이름과 「레시피북에서 보기」 버튼(아직 몰라도 이름과 힌트) |
| 모호한 말 | 「너무 세지 않게, 달달한 걸로요」 | 칩도 게이지 목표 구간도 없음. 서빙하면 결과 기사가 정답 조건을 알려 줍니다 |

모호한 말은 늘 같은 뜻으로 씁니다: 달달하게 = 단맛 2 이상, 쌉쌀하게 = 단맛 -1 이하, 너무 세지 않게 = 도수 1 이하, 화끈하게 = 도수 3 이상, 가볍게 = 바디 0 이하, 솔직하게·시원시원하게 = 경향 2 이상, 은근하게·에둘러서 = 경향 -2 이하.

### 경향 축 (Day 4부터)

Day 4부터 새 맛 축 **경향**(완곡함 ↔ 직설적)이 등장합니다. 재료마다 경향 값이 있고(진·시트러스·소다 +1, 위스키·비터스·에스프레소 +2, 와인·미드 -1, 시럽·크림·성운 -2), 경향 조건이 있는 주문에서는 게이지에 **도수 대신 경향**이 나옵니다(그런 주문에는 도수 조건이 없습니다).

### 실시간 하루

- 게임 속 1시간은 실제 45초라서 하루가 약 7분 반입니다(하루 손님이 8~16명이라 v6의 30초보다 느리게).
- 손님은 **무작위로, 띄엄띄엄** 옵니다. 손님마다 밤(18:10~01:40 무렵)을 손님 수만큼 나눈 칸 안의 아무 시각을 기준 시각으로 받고, 앞 손님이 들어온 뒤 **5~15분**(스툴이 하나뿐이던 예전의 15~45분을 3분의 1로)은 지나야 다음 손님이 옵니다. 스툴 넷이 모두 차 있으면 자리가 날 때까지 들어오지 않습니다. 어느 스툴에 앉을지도 무작위입니다. 도착 일정과 자리는 날마다 시드가 고정되어 같은 날은 늘 같습니다.
- **인내**는 게임 속 4시간(실제 3분)입니다. 지금 잔을 만들어 주는 손님의 인내는 줄지 않고, 시계가 멈춘 동안에도 줄지 않습니다.
- **01:00까지는 반드시 영업**합니다. 그 뒤로는 시계 옆에 **조기 마감** 버튼이 나옵니다(오늘 더 올 손님이 없으면 은은하게 깜빡입니다). 조기 마감하면 아직 오지 않은 손님은 오지 않습니다.
- **04:00이 지나면** 새 손님은 오지 않고, 앉아 있는 손님은 계속 기다립니다(인내가 다하면 떠남). **다음 날로** 버튼이 강조되어 깜빡입니다.
- 마감 버튼은 스툴에서 기다리는 손님이 없을 때 누를 수 있습니다(잔을 주거나 돌려보내면 됩니다).
- 메뉴·레시피북·하루 시작/마감 화면·이야기 만화·대화 카드가 열려 있거나 탭을 떠나 있으면 시계가 멈춥니다. 서랍과 수첩은 열어 둬도 시간이 흐릅니다.
- 잔을 받고 할 말이 남은 손님이 스툴에 있으면 마감할 수 없습니다(이야기를 듣거나, 머무는 시간이 끝나 일어나면 됩니다).

### 재료 잔량

- 병마다 **100%에서 시작해 한 번 부을 때마다 10%씩** 줄어듭니다(가득 찬 병으로 열 번). 재료 카드 아래 칸이 남은 양을 보여 주고, 빈 병(0%) 카드는 잠깁니다. 붓는 데는 돈이 들지 않습니다.
- **리필**은 서랍(또는 마감 뒤 상점)에서 언제든 주문할 수 있고, **다음 날 아침** 병이 가득 찹니다. 「덜 찬 병 모두 리필」로 한 번에 주문할 수도 있습니다. 잔고가 모자라도 외상(빚)으로 주문할 수 있어, 빈 병만 남아 영업이 막히는 일은 없습니다.
- 새로 입고된 재료와 미리 들여온 재료는 가득 찬 병으로 옵니다. 영업 시작 화면에 잔량이 적은 병이 표시됩니다.
- 병이 모두 가득 차 있으면 그날 손님의 주문을 **한꺼번에 모두** 완벽하게 만들 수 있음을 테스트가 확인합니다.

### 무한 영업과 자유 제조

- 7일 결산 뒤 **무한 영업 이어가기**를 고르면 Day 8부터 계속 엽니다. 하루 14~16명이 오는데, 단골 2~4명이 검증된 주문(캠페인 주문 가운데 그날 이야기에 묶이지 않은 것, 레시피 이름 주문)을 들고 오고 나머지는 지나가는 손님입니다. 날마다 시드가 고정되어 같은 날은 같은 손님이 오고, 같은 단골은 하루에 한 번만 옵니다. 7일 결산 뒤에는 장보기를 거치지 않으므로, 축제 답례로 빈 병이 모두 채워진 채 Day 8을 시작합니다. 임대료는 Day 7 수준(✦80)에서 더 오르지 않습니다.
- **자유 제조**는 손님·시계·잔량 없이 그때까지 입고된 재료로 실험만 합니다(바로 제조대가 열립니다). 경향 축이 나온 뒤라면 게이지에 네 축이 모두 보입니다.
- **레시피북**: 오른쪽 위 「레시피북 n/12」 버튼으로 엽니다. 찾은 레시피는 정확한 조건도 함께 보입니다.
- **서랍**: 오른쪽 아래 「서랍」 탭으로 엽니다. 잔고와 오늘 장부(마감 때 낼 임대료 포함), 병별 잔량과 리필, 가게 꾸미기, 재료 미리 들여오기가 있습니다. 빈 병이 있으면 탭에 빨간 표시가 붙습니다.

하루 손님은 첫날 8명에서 마지막 날 14명까지 늘고, 단골은 밤마다 일정표에 이름이 있는 사람만 옵니다(테스트가 확인). 지나가는 손님의 주문은 그날 입고된 재료로 만들 수 있게 만들어지고, 병이 가득 차 있으면 그날 주문을 한꺼번에 모두 만들 수 있습니다.

- 주문 조건은 첫날 2개에서 마지막 날 3~5개(잔·얼음·젓기·층·장식·맛 키워드 지정 포함)로 늘어납니다. 모든 주문은 그날까지 입고된 재료만으로 완벽하게 만들 수 있음을 테스트가 확인합니다.
- 돈: 시작 ✦30. 한 잔 판매가 ✦20에 팁(완벽 30, 아쉬움 10, 실패 0). **붓는 데는 돈이 들지 않고**, 장식은 올릴 때(✦1~3) 나갑니다. 돌려보내거나 기다리다 떠난 손님은 돈을 내지 않습니다.
- **리필**(병 하나를 가득): 소다 ✦4, 시럽·시트러스 ✦6, 진·크림 ✦10, 위스키·와인·에스프레소 ✦12, 비터스·미드 ✦14, 성운 ✦16. 리필과 장식 값은 장부의 「리필·장식」에 들어갑니다.
- 하루 마감 때 임대료가 나갑니다(Day 1 ✦20부터 하루 ✦10씩 올라 Day 7 ✦80, 그 뒤로는 그대로). 돈이 모자라면 빚(빨간 숫자)으로 넘어갑니다.
- 서랍이나 마감 뒤 상점에서 가게를 꾸밀 수 있습니다: 도매 계약(리필·장식 -30%, ✦60), 벨벳 의자(판매가 +5, ✦70), 별빛 축음기(실패해도 판매가 절반, ✦80), 바 조명 정비(팁 +50%, ✦90). 나중에 들어올 재료를 ✦40에 미리 주문할 수도 있습니다(다음 날 가득 찬 병으로 도착).
- 7일이 끝나면 남은 돈과 완벽한 잔 수로 칭호를 받고, 약속 장부에서 그은 줄 수와 다섯 줄기의 결말이 함께 실립니다. 진행(돈·꾸미기·입고·병 잔량·만난 손님·진열장·이야기)은 매일 아침 브라우저에 저장되어 이어서 할 수 있습니다.
- 저장 형식은 **버전 5**입니다(진열장 재고 `goods`, 이야기 `story`: 깃발·신뢰·맡은 것·끝난 장면·기록·신문·결말, v7에서 신문 재료인 선택 기록 `deeds`·밤마다의 장사 기록 `nights`·지난 신문 `papers` 추가). 버전 4 저장은 그대로 이어지되 병 잔량을 열 번 단위로 옮기고(남은 비율 유지), 첫 아침 신문은 그날의 기본 기사로 시작합니다. 버전 1~3 저장은 이야기를 처음부터 시작하고 진열장에 첫날 물건(엽서 3·별사탕 2)을 놓은 채 이어집니다. 버전 3은 만난 손님 `met`을, 버전 2는 그날 이전에 나온 손님을 만난 것으로 채우고, 잔량이 없던 버전 1은 병을 모두 가득 채웁니다. 모르는 장면·맡은 것·깨진 값은 읽을 때 버립니다.

## 그래픽

외부 이미지 없이 모두 코드로 그립니다.

- **화풍(v7 신문·극화)**: 먹(`--ink`)·종이(`--paper`)·빨강(`--red`) 세 가지가 주인공이고 나머지는 회색 단계입니다. 종이 잡티(SVG 노이즈)·하프톤 점·45도 망점으로 질감을 내고, 비스듬한 카드·단단한 먹 그림자·빠른 화면 넘김을 씁니다. 제목은 글자마다 오려 붙인 듯한 신문 글자(`src/ui/ransom.ts`)입니다. 색은 `src/style.css` 맨 위 토큰에 모여 있고(v6에서 쓰던 토큰 이름은 지우지 않고 값만 신문 쪽으로 바꿨습니다), 흰 글자를 얹는 빨강 바탕·작은 회색 글자는 명도 대비 4.5:1 이상으로 맞췄습니다.
- **가게(2D)**: SVG 한 장면입니다. 꾸밈을 덜어 문·달이 보이는 창·술병 선반 하나·매달린 등 하나·카운터·스툴만 남겼습니다. 가게는 손님 등 뒤에서 카운터를 보는 구도라서, 손님은 걸어 들어오고 나갈 때는 앞모습, 스툴에 올라앉는 순간 몸을 돌려 **뒷모습**(뒷머리·모자·어깨·옷 뒤판)이 됩니다. 이름표·인내 막대·「…」·말풍선은 머리 위에 뜨고, 잔을 받은 반응은 뒤에서도 읽히게 머리 옆 감정 표시로 나옵니다.
- **손님(극화체)**: 신문 만화 원고처럼 굵고 단단한 먹선(그늘 쪽 윤곽은 더 굵게), 빗금(해칭)과 망점(스크린톤) 그늘, 각진 얼굴·깊은 눈두덩·짙은 눈썹, 8~9등신 비율에 손을 허리에 짚거나 턱에 대는 과장된 자세를 줍니다. 특정 작품의 인물을 본뜨지 않고 화풍만 빌렸습니다. 한 사람에 빨강은 한 군데만 씁니다. 단골 여덟 명과 지나가는 손님은 같은 부품(머리 모양·모자·윗옷·자세·얼굴 특징)으로 조립하고, 지나가는 손님은 손님 id로 부품을 골라 같은 손님은 늘 같은 모습입니다. 표정은 다섯 벌(평소·완벽·좋음·실망·화남)이고, 대화·주문 카드·단골 수첩·신문 사진의 얼굴은 앞모습입니다. 빗금·망점·그늘 가림은 문서에 한 번만 넣는 공통 정의를 참조해서 손님이 많아도 가볍습니다. 숨쉬기·걷기·앉기·발 구르기·반응·잔을 들고 나가기를 CSS와 시간 계산으로 움직입니다. 화면 비율에 맞춰 보이는 영역이 바뀌어 넓은 화면과 휴대폰 세로 화면 모두에서 스툴 넷이 다 보입니다.
- **제조대(3D, Three.js)**: 셀(툰) 셰이딩 재질에 마지막 후처리로 먹선(깊이·밝기 변화), 종이색 스티커 테두리, 흑백+빨강 쪽으로 당긴 색 정리, 45도 하프톤 점을 입혀 신문 그림처럼 보이게 합니다. 카운터는 하프톤 점이 앉는 회색 윗면에 검은 앞면과 빨간 띠입니다. 캔버스 배경은 투명해서 뒤의 DOM 신문지 콜라주가 비칩니다. 잔은 굴절 대신 먹선 테두리·흰 에칭 띠로, 술은 층마다 재료 효과(소다 기포, 성운의 빛구름과 별, 크림 마블, 미드 금가루)를 셰이더로 그립니다.
- **화면 전환**: 가게 ↔ 제조대는 사선으로 자르는 와이프로 넘어갑니다. 움직임 줄이기 설정에서는 옅은 페이드로 바뀌고 장식 반복 움직임이 멈춥니다.
- **제조대 배치**: 주문 카드는 왼쪽 위, 맛 게이지는 잔을 고른 뒤 왼쪽 아래, 단계 판은 오른쪽에 두고, 3D 잔은 그 사이 빈 영역 가운데에 오도록 카메라를 맞춥니다. 휴대폰에서는 주문 카드가 한 줄로 접히고(▾로 펼침) 단계 판이 아래에서 올라옵니다. 장식 카드는 고른 카드 자리에서 부채꼴로 펼쳐지며 들어오고, 움직임 줄이기에서는 짧게 흐려졌다 나타나기만 합니다.
- **아이콘**: 병·잔·얼음·장식 아이콘도 같은 화풍의 SVG입니다(`src/ui/icons2d.ts`).
- **품질**: 제조대 화소 배율(높음 최대 2, 낮음 최대 1.25)과 입자 수를 조절합니다. 화소 밀도가 2.25를 넘는 기기는 낮음으로 시작하고, 프레임이 계속 느리면 자동으로 낮춘 뒤 해상도를 낮춥니다. 주소에 `?quality=high` 또는 `?quality=low`를 붙이면 고정합니다. 제조대가 보이지 않을 때는 3D를 그리지 않습니다.

새 손님 주문은 `src/campaign.ts`의 날짜별 `visits`에 `chips`·`speech`(대사 속 조건 표현을 `{…}`로 감싸 조건 순서대로)·`named`(레시피 이름)·`vague` 중 하나로, 레시피는 `src/data.ts`에 조건(`Constraint`, 맛 키워드는 `{ kind: 'keyword' }`)으로 추가하면 됩니다. 테스트가 그 조건을 그날 재료로 실제로 만들 수 있는지, 병이 가득 차 있을 때 그날 주문을 한꺼번에 만들 수 있는지, 표현 방식 규칙(강조 수 = 조건 수, 경향 주문은 Day 4부터·도수 조건 없음 등)을 자동으로 확인합니다.

이야기 장면은 `src/story.ts`의 `BEATS`에 손님(`who`)·잔을 받기 전/뒤(`when`)·나올 수 있는 날(`days`)·조건(`need`)·우선순위(`prio`)·대사·선택지(조건 `need`/`show`, 잠긴 이유 `locked`, 효과 `fx`)로 추가합니다. 테스트(`src/story.test.ts`)가 읽는 깃발은 모두 어떤 선택이 세우고 세운 깃발은 모두 어딘가에서 읽히는지, 맡긴 것은 모두 건네지거나 묻힐 수 있는지, 전언 장면에 그대로·완곡·직설·묻어 두기가 모두 있는지, 손님마다 장면·소문·고백·수첩·무한 영업 대사가 있는지, 고백의 잔을 실제 주문과 함께 만들 수 있는지 확인합니다. 또 무작위로 고르는 바텐더 2천 명이 7일을 영업해 보며 막히는 장면이 없는지, 모든 장면이 한 번 이상 나오는지, 다섯 줄기의 모든 결말에 닿는지, 잘 이어 주면 모든 줄기가 가장 좋은 결말과 약속 장부 여덟 줄에 닿는지 검사합니다.

화면 검증용으로 주소에 `?debug`를 붙이면 `window.__perfect()`(지금 손님의 주문을 완벽하게 맞춘 잔을 곧바로 서빙, `{ key: true }`로 열쇠 맛, `{ tone: -1 }`로 경향 부호 지정), `window.__talk()`, `window.__story()`, `window.__night()`(오늘 손님 줄과 결과, 오늘 아침 신문 1면 제목), `window.__clock()`(게임 시계와 흐르는지), `window.__comic()`(이야기 만화의 칸 목록과 펼친 상태), `window.__comicPreview('mio_box', { picked: 0, mood: 'good' })`(아무 장면이나 이야기 만화로 띄워 보기, 선택지는 모두 열림)를 쓸 수 있습니다.
