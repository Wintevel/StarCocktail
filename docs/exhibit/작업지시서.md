# 「향을 짓는 바」 작업지시서

개발자(GPT/Codex)는 위에서부터 **한 번에 한 작업**씩 한다. 끝나면 체크하고, 확인한 화면 크기와 남은 문제를 「메모」에 한두 줄 적는다.
막히거나 기획과 다르게 가야 할 것 같으면 코드를 바꾸기 전에 「질문」 칸에 적고 멈춘다(기획 담당 Claude가 답한다).

마감: 2026-11-21(토) 23:59 KST 제출. **금요일(11-20) 밤까지 T1~T7, 토요일 낮까지 T8~T10.**
공통 확인: `npx tsc --noEmit`, `npm test` 통과, `npm run dev` 후 `/exhibit.html?idle=0`에서 콘솔 오류 0, 1920×1080·1366×768·1280×720에서 겹침·잘림 없음.

## T1. 제출용 단일 HTML 빌드 (가장 먼저: 제출 위험 제거)
- `vite-plugin-singlefile`로 전시판만 단일 파일로 뽑는 설정을 따로 만든다: `vite.exhibit.config.ts`, 스크립트 `npm run build:exhibit` → `dist-exhibit/index.html`.
- 글꼴·그림·.glb가 모두 파일 안에 들어가야 한다(`assetsInlineLimit` 크게, `.glb`는 `?url` import로 data URL).
- 한글 글꼴 줄이기: 빌드 후 CSS의 `@font-face` 중 `unicode-range`가 **`src/exhibit/` 안 글자(+ 본편에서 가져다 쓰는 화면 글자)와 하나도 안 겹치는 것**은 지우는 작은 Vite 플러그인을 `scripts/`에 만든다.
- 완료 기준: `dist-exhibit/index.html`을 **파일로 더블클릭(file://)** 해서 Chrome에서 끝까지 플레이된다(네트워크 요청 0). 크기 15MB 이하. 크기를 메모에 적는다.

- 3D 잔·카운터(`Stage3D`)도 종이 톤에 맞춘다: 전시판에서만 조명색을 따뜻한 흰색으로, 외곽선은 먹색. 본편 파일을 바꿔야 하면 `Stage3D`에 옵션(예: `theme: 'paper'`)을 추가하는 식으로 본편 기본값은 그대로 둔다.
- 손님 등장 위치가 이야기 카드와 겹치는 문제를 고친다(지금 1600×900에서 겹침).

## T3. 향이 닿은 곳만 색종이 (이 작품의 핵심 연출)
- 기획서 「구현 권장안」대로 두 겹(색 있는 판 / 색 빠진 판) + 격자 마스크.
- `vapor.ts`: 연기 밀도를 읽을 수 있게 `densityGrid(cols, rows): Float32Array`를 추가. 연기 모양은 옅은 먹선 곡선 몇 가닥 + 작은 색종이 조각으로 바꾼다.
- 칸이 열리고 닫힐 때 툭 붙고 떨어지는 짧은 움직임(크기 0.9→1, 120ms). 너무 깜빡이지 않게 칸마다 최소 0.6초는 유지.
- 시향(병 위에 마우스): 그 병 주변 반경만 열린다. 붓기: 잔 주변이 점점 넓게 열린다. 향 띄우기: 화면 가운데부터 크게 열린다.
- 성능: 1920×1080에서 60fps 근처(최소 40fps). `requestAnimationFrame` 안에서 마스크 갱신은 초당 15~20번만.
- 완료 기준: 병에 마우스를 올렸다 떼면 색종이가 붙었다 3초 안에 다시 비워지는 것이 보인다. 짧은 화면 녹화(gif) 남기기.
